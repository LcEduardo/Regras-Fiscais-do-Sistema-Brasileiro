Precisa ser uma série entre 10001 e 49999. A série que ela passou, 00001, é reservada exclusivamente para emissões realizadas no próprio sistema municipal. Para webservice é 10001 - 49999

Atividade municipal são três dígitos. Na prefeitura está assim:

O campo **Código Complementar Municipal** => 14.01.01.045, 
- 14.01.01 => Código Nacional (140101 sem pontos);
- 045 é o código municipal que dever ser colocado;
